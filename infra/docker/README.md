# Docker

O runtime local continua centralizado no arquivo [`compose.yaml`](/home/lucaslisilva/projetos/CashFlow/compose.yaml) na raiz do repositorio.

Esta pasta existe para documentar a trilha de evolucao da infraestrutura local. Quando o projeto crescer, ela pode acomodar:

- `compose.override.yaml`
- `compose.app.yaml`
- arquivos auxiliares de bootstrap local

Por enquanto, a regra e manter o compose principal simples e orientado a infraestrutura base.
