# Infraestrutura

Esta pasta organiza a evolucao da infraestrutura do projeto em duas trilhas:

- `docker/`: referencia para runtime local e composicao dos servicos usados no desenvolvimento.
- `terraform/`: espaco reservado para futura infraestrutura declarativa de cloud, quando houver alvo real de deploy.

A decisao atual do projeto e manter a infraestrutura local como prioridade e evitar acoplar provisionamento cloud antes do momento certo.
